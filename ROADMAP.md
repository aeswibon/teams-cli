# Roadmap

This roadmap focuses on documentation, distribution, and quality. It is not a promise of specific features or timelines.

## Now

- Tighten and simplify the README and authentication guidance
- Improve error messages and troubleshooting docs for common Graph failures (401/403/429)
- Make releases easier to consume (clear install paths and checksums)
- Expand CI checks for formatting, linting, and security scanning

## Next

- Add richer documentation for advanced usage (filters, pagination behavior, JSON workflows)
- Publish and document shell completions and man pages
- Improve release automation and artifact consistency across platforms
- Increase test coverage around request building and response parsing

## Later

- Documentation site or rendered docs beyond the README
- More automated quality gates (dependency updates, SBOM generation, reproducible builds)
- Wider packaging options (community-maintained formulas/ports)
