# Support

## Where To Ask

- If GitHub Discussions are enabled for this repository, please use **Discussions** for questions and help.
- Otherwise, open a **GitHub Issue**.

For suspected vulnerabilities or security-sensitive reports, do not open a public issue. Follow `SECURITY.md` instead.

## What To Include

To help us respond quickly, include:

- What you expected to happen and what actually happened
- Command you ran (with flags)
- `teams-cli --version` and your OS/arch
- Whether you are using MSAL, `TEAMS_CLI_TOKEN`, or `--api-key` (do not paste secrets)
- Relevant output with tokens and IDs redacted
- If applicable: the Graph endpoint you hit and the HTTP status code
